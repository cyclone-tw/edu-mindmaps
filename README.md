依學年度整理的國小課文互動心智圖，給老師上課投影、給學生自己複習。

網站：https://cyclone-tw.github.io/edu-mindmaps/

## 怎麼用

- **學生**：打開學年度頁面，點課名就會打開那一課的心智圖。點主題可以展開或收合，拖曳可以移動，捏合或 Ctrl＋滾輪可以縮放。
- **老師**：在學年度頁面右上角打開「老師工具」，就會出現：
  - 各課 PNG、PDF 下載
  - 全冊 PDF
  - 給學生掃的 QR code
- **心智圖頁面**：可以切換左右開展或向右展開，也能換配色（含高對比）、字體、字級。投影時可以把工具列收成一顆按鈕。
- **網址參數**：可以直接指定樣式，例如 `?theme=contrast&font=yuan`。

## 目錄結構

```
index.html              首頁：學年度清單
site.json               目錄資料（學年度 → 冊 → 課）
115/index.html          115 學年度入口
115/6-1/01.html         六上第一課心智圖（6-1 = 六年級上學期）
115/6-1/01.png, 01.pdf  該課 PNG 與 A4 PDF
115/6-1/all.pdf         六上全冊 PDF
```

## 著作權

課文內容的著作權屬於原教科書出版社。本站心智圖是教學整理，只收錄重點摘要與少量引文，不收錄課文全文，供課堂學習使用。
